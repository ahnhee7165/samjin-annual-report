# 삼진어묵 2025 vs 2026 광고 성과 분석

## GitHub Pages 배포
1. GitHub 새 저장소를 생성합니다.
2. ZIP 안의 `index.html` 파일을 저장소 최상위(root)에 업로드합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. 잠시 후 `https://사용자명.github.io/저장소명/`으로 접속합니다.

별도 설치나 API 키가 필요 없는 단일 HTML입니다. 데이터는 HTML에 내장되어 있어 `index.html`만 업로드하면 됩니다.

## 주의사항
- 2025년 모비온 원본은 10월 17일부터 기록되어 동기간 연간 비교가 불완전합니다.
- 매체별 전환 가치는 중복 기여가 가능하며 실제 자사몰 매출과 다릅니다.
- 네이버 브랜드검색 별도 광고비는 이 8개 파일만으로 포함 여부를 확정할 수 없습니다.
- 메타는 '노출수'가 아닌 '도달' 열이 있으므로 클릭률 직접 비교를 피했습니다.
- 2026년 설/추석 기간은 기존에 제공된 운영 일정(1/8~2/18, 8/14~9/24)을 적용했습니다.
- 2027년 설 운영 전략과 예상 매출은 제안·시나리오이며 확정 성과가 아닙니다.
